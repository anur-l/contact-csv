# Contact Manager (Python CLI)

A simple command-line contact management system that supports adding, viewing, updating, searching, and deleting contacts stored in a CSV file.

## Features
- Add new contacts
- View all contacts
- Search contacts
- Update contact information
- Delete contacts
- Persistent storage using CSV

## File Structure
- contact.py → main application logic
- contact.csv → data storage file
- test/ → testing files (if any)

## How to run
```bash
python contact.py
